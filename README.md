# BOARDROOM 8

仕入れ・生産・販売・決算を繰り返しながら、会社を8期経営する1人用の経営シミュレーションゲームです。

ブラウザだけで動作し、サーバーや外部APIは必要ありません。PCとスマートフォンの両方に対応しており、GitHub Pagesで無料公開できます。

> 本作は、経営研修で扱われる考え方を参考にした独自の学習ゲームです。特定の公式MG、教材、ルールを再現するものではありません。

## ゲームの目的

プレイヤーは会社の経営者として、毎期次の意思決定を行います。

- 原材料の仕入れ
- 製品の生産
- 販売価格の設定
- 広告費の設定
- 社員の採用
- 生産設備への投資

市場の景気やランダムイベントに対応しながら会社を8期経営し、最終的な自己資本をできるだけ大きくすることが目標です。

## 主な機能

- 全8期の経営シミュレーション
- 景気に応じて変化する市場需要
- 販売価格と広告費による需要の変化
- 社員採用と設備増設による生産能力の拡大
- 売上高、費用、利益、現金残高の決算表示
- 物流費上昇や競合の値下げなどのランダムイベント
- 各期の経営成績を確認できる経営記録
- 最終自己資本に基づく経営評価
- `localStorage` を使用したプレイ状況の自動保存
- PC・タブレット・スマートフォン対応
- GitHub Pagesへの自動デプロイ

## 遊び方

1. 市場の景気と基準需要を確認します。
2. 原材料の仕入数と製品の生産数を設定します。
3. 販売価格と広告費を決定します。
4. 必要に応じて社員の採用や設備増設を選択します。
5. 「この計画で第○期を実行」を押します。
6. 決算結果を確認し、次期の経営計画を立てます。
7. 8期終了時の自己資本と経営評価を確認します。

現金がマイナスになると倒産です。売上だけでなく、在庫、固定費、設備投資後の資金残高にも注意してください。

## 経営ルール

| 項目 | 内容 |
| --- | --- |
| 初期資金 | 300万円 |
| 経営期間 | 全8期 |
| 原材料費 | 1個につき3万円 |
| 加工費 | 製品1個につき2万円 |
| 製品の材料 | 製品1個につき原材料1個 |
| 社員採用 | 15万円、生産能力が5個増加、固定費が4万円増加 |
| 設備増設 | 35万円、生産能力が10個増加、固定費が3万円増加 |
| 在庫保管費 | 売れ残った製品1個につき0.5万円 |

販売需要は、景気、販売価格、広告費、ランダムイベントによって変化します。

## 動作方法

### ファイルを直接開く

`dist/index.html` をブラウザで開くとプレイできます。

ブラウザの制限によって正常に読み込めない場合は、次のローカルサーバーを使用してください。

### Pythonを使用する場合

```bash
python3 -m http.server 8000 --directory dist
```

起動後、ブラウザで次のURLを開きます。

```text
http://localhost:8000
```

### Visual Studio Codeを使用する場合

1. Visual Studio Codeでプロジェクトを開きます。
2. 拡張機能「Live Server」をインストールします。
3. `dist/index.html` を右クリックします。
4. **Open with Live Server** を選択します。

## GitHub Pagesで公開する

このプロジェクトには、`dist` フォルダーをGitHub Pagesへ公開するGitHub Actions設定が含まれています。

### 1. リポジトリを作成する

GitHubで新しいリポジトリを作成します。公開サイトとして使用する場合は、通常はPublicリポジトリを選択します。

### 2. ファイルをアップロードする

このプロジェクトのすべてのファイルをリポジトリへ追加します。

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

`ユーザー名` と `リポジトリ名` は、自分のGitHub環境に合わせて変更してください。

### 3. GitHub Pagesを有効にする

1. リポジトリの **Settings** を開きます。
2. 左側のメニューから **Pages** を選択します。
3. **Build and deployment** の **Source** を **GitHub Actions** に変更します。
4. リポジトリの **Actions** タブを開きます。
5. `Deploy GitHub Pages` が完了するまで待ちます。

公開後のURLは通常、次の形式です。

```text
https://ユーザー名.github.io/リポジトリ名/
```

以後は、`main` ブランチへ変更をpushするたびに最新版が自動公開されます。

## ゲーム内容を変更する

主な設定は `dist/game.js` で変更できます。

| 変更する内容 | 該当箇所 |
| --- | --- |
| 経営する期数 | `MAX_ROUNDS` |
| 原材料費 | `MATERIAL_COST` |
| 加工費 | `PRODUCTION_COST` |
| 採用費 | `EMPLOYEE_COST` |
| 設備費 | `MACHINE_COST` |
| 初期資金・初期在庫 | `initialState()` |
| 景気と基準需要 | `marketStates` |
| ランダムイベント | `events` |

変更後にページを再読み込みしても以前のプレイ状況が表示される場合は、ゲーム画面右上の「最初から」を押してください。

## 注意事項

- セーブデータはプレイ中のブラウザ内にのみ保存されます。
- 別の端末やブラウザにはセーブデータが引き継がれません。
- ブラウザのサイトデータを削除すると、プレイ状況も削除されます。
- このゲームは経営判断の学習を目的としたもので、実際の企業会計を完全に再現するものではありません。
