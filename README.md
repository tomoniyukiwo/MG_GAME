# MARKET MAKERS

カードを引きながら、材料購入・生産・採用・設備投資・入札販売・期末決算を行うブラウザ向け経営シミュレーションゲームです。

- 1人用：AI企業3社と対戦
- オンライン：ルームコードで2～6人対戦
- ホストが期数と各期の手番数を設定
- 意思決定カード70%・リスクカード30%
- GitHub Pages対応

> 本作は、公開されているルール情報とユーザー指定の仕様を基に独自実装した学習ゲームです。市場名・材料単価・販売上限・市場容量は公開されている市場盤面を参照していますが、公式教材の図表や画面デザインは複製していません。

## ターンの流れ

1. 自分の手番でカードを1枚引きます。
2. 意思決定カードなら、ルールAを1回実行できます。
3. リスクカードなら、表示されたイベントが直ちに適用されます。
4. カードを引いてから手番終了まで、ルールBを何回でも実行できます。
5. 「手番を終了」を押すと次の会社へ移ります。

## ルールA

意思決定カードを引いた手番に1回だけ実行できます。

### 材料購入

複数市場をまたいで、一度に材料を購入できます。マーチャンダイザーを持つ会社は、材料を市場価格より2万円安く購入できます。市場残量は材料購入と商品販売で共通して消費します。

| 市場 | 材料単価 | 販売上限 | 市場容量 |
| --- | ---: | ---: | ---: |
| 札幌 | 12万円 | 20万円 | 4個 |
| 仙台 | 12万円 | 20万円 | 4個 |
| 東京 | 16万円 | 32万円 | 10個 |
| 名古屋 | 13万円 | 24万円 | 6個 |
| 大阪 | 15万円 | 28万円 | 8個 |
| 福岡 | 13万円 | 24万円 | 6個 |

### 設備投資

| 設備 | 価格 | 基本生産能力 | 必要人員 |
| --- | ---: | ---: | ---: |
| 小型機械 | 100万円 | 1個 | ワーカー1人 |
| アタッチメント | 30万円 | 小型機械の能力を1増加 | 追加人員なし |
| 大型機械 | 200万円 | 4個 | ワーカー1人 |

小型機械1台につき、装着できるアタッチメントは1つです。ワーカー1人につき機械1台しか動かせません。稼働させる機械は、能力の高い設備から自動選択されます。

### 投入／完成

- 投入：材料を仕掛品へ移動
- 完成：仕掛品を商品へ移動
- 投入数と完成数は、それぞれ設備の生産能力まで指定可能
- 投入費は完成費の2倍

生産能力1の場合、同じ手番に「投入1個・完成1個」を実行できます。

### 採用

ワーカーまたはセールスマンを1手番に3人まで採用します。採用費は1人5万円で、採用した人員を会社都合で退職させることはできません。

### 広告チップ

1枚20万円で、販売能力が2個増加します。セールスマン1人につき2枚まで有効です。1手番で複数枚購入できます。

### 研究開発

1枚20万円で、価格競争力が2増加します。1手番に1枚だけ購入できます。

### 販売

販売を開始した会社が「親」となり、複数市場へ数量と表示価格を提示します。他社は「子」として、親が提示した市場だけに参加できます。

- 子の提示数量は各市場で親の提示数量以下
- 全市場の販売数量合計は自社の販売能力以下
- セールスマン1人の基本販売能力は2個
- 親は価格競争力を2獲得
- 研究開発1枚につき価格競争力を2獲得
- マーケットリサーチ保有会社は価格上限より2万円高く提示可能
- 競争価格が同じ場合は研究開発枚数を優先
- 研究開発枚数も同じ場合はランダムに決定

実際の売上には表示価格を使い、落札順位の判定には価格競争力を差し引いた競争価格を使います。

## ルールB

カードを引いてから手番を終了するまで、資金がある限り何回でも実行できます。PAC生産性・マーチャンダイザー・マーケットリサーチは各社1回だけ取得でき、取得後のボタンは「取得済み」になります。

| 行動 | 効果 |
| --- | --- |
| 保険 | 火災・盗難の保険金を受け取る。使用後はチップを1枚返却 |
| PAC生産性 | 稼働する機械1台につき生産能力を1増加 |
| マーチャンダイザー | 材料を2万円安く購入 |
| マーケットリサーチ | 市場の価格上限より2万円高く販売可能 |
| 配置転換 | ワーカーとセールスマンを1人単位で相互転換 |
| 機械売却 | 購入価格の1/2で設備を売却 |
| 銀行借入 | 借入回数に応じて金利15%・10%・5%、限度2倍・3倍・4倍 |
| 借金返済 | 金利の高い借入から元本を返済 |

## リスクカード

| カード | 効果 |
| --- | --- |
| 盗難 | 商品を1～3個失う。保険があれば10万円を受領 |
| 火災 | 材料をすべて失う。保険があれば8万円を受領 |
| 故障 | 仕掛品を1～3個失う |
| 研究開発成功 | 研究開発枚数に応じて、価格上限より1万円低い価格で独占販売 |
| 消費者運動 | 次の自分の手番まで販売不可 |
| ワーカー退職 | ワーカーが1人減少 |
| 広告成功 | 広告チップ枚数に応じて独占販売 |

独占販売された商品は市場需要を消費し、ストッカー行として扱います。

## 期末処理

各社が設定された手番数を終えると決算を行います。

- 借入ごとの金利支払い
- ワーカー・セールスマンの給与
- 商品在庫の保管費
- 材料・仕掛品・商品の棚卸評価
- 売上高
- 変動費と変動単価
- 付加価値と単位付加価値
- 固定費
- 利益
- 損益分岐点数量・損益分岐点売上高
- 資産・負債・自己資本
- 損益計算書
- 貸借対照表

「決算履歴」から過去の各期をいつでも確認できます。

## ローカルで実行

1人用は `dist/index.html` を直接開いてプレイできます。オンライン機能の確認にはローカルサーバーを使用してください。

```bash
python3 -m http.server 8000 --directory dist
```

ブラウザで <http://localhost:8000> を開きます。

## オンライン対戦の設定

1. [Firebase Console](https://console.firebase.google.com/)でプロジェクトとWebアプリを作成します。
2. Authenticationで匿名認証を有効にします。
3. Realtime Databaseを作成します。
4. `database.rules.json` の内容をRealtime DatabaseのRulesへ設定します。
5. `dist/firebase-config.js` にWebアプリの設定を入力します。

```javascript
window.firebaseConfig = {
  apiKey: "...",
  authDomain: "プロジェクトID.firebaseapp.com",
  databaseURL: "https://プロジェクトID-default-rtdb.firebaseio.com",
  projectId: "プロジェクトID",
  appId: "..."
};
```

## GitHub Pagesで公開

1. プロジェクト一式をGitHubリポジトリへpushします。
2. **Settings → Pages** を開きます。
3. Sourceを **GitHub Actions** にします。
4. `Deploy GitHub Pages` の完了を待ちます。

`.github/workflows/pages.yml` が `dist` を自動公開します。

## 運用上の注意

現在のオンライン版は、少人数で遊ぶ試作版です。参加者のブラウザからゲーム状態を更新するため、不正対策が必要な大会や賞金付き対戦には適していません。本格運用では、カード抽選、入札判定、会計処理をサーバー側へ移してください。
